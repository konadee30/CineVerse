CineVerse movie detail pages

Each movie has its own HTML page. The category pages (Action, Adventure, Horror, Romance and Science Fiction), Explore Movies and Homepage now link to the corresponding movie detail page.

To add a new movie: copy movie-template.html (if present) or one of the existing detail pages, rename it, change its title/poster/description/metadata, then add a movie card linking to that filename in the appropriate category page and explore.html.

Some fields are marked Not listed when the original project did not provide that information. Add your own information when you have it.

This project uses HTML, CSS and Bootstrap only; no JavaScript is used.
